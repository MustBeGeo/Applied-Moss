# Applied Moss
Right-click cobblestone and stone bricks with moss to create their mossy variants
A change to how mossy blocks in the game are interacted with, designed to reduce inventory clutter when building with stone blocks and their mossy variants.

## Notes
This pack was designed for Minecraft version 26.3

## Additions and changes
### Moss 
A new item obtained by crafting five moss from one moss block. The moss item cannot be crafted back into moss blocks. While holding moss, right-click on cobblestone or stone bricks (or one of their shaped variants) and it will become its mossy equivalent.

### Removed crafting
This datapack removes the crafting recipes for all mossy variants from both the crafting table and the stonecutter. The only way to obtain mossy variants is through the new moss item, or the creative mode menu.

### "It's Growing On Me" Advancement
One advancement has been added in the Husbandry tab as a hint towards the new moss mechanics.
